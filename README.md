# FiveM Car Dealership

A complete car dealership system for FiveM servers.

## Features

- Multiple dealership locations with blips and markers
- Car browsing and purchasing system
- Integration with ESX economy

## Requirements

- FiveM server
- ESX framework
- MySQL database

## Installation

1. Download the script
2. Place the script in your FiveM resources folder
3. Add `start car_dealership` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

1. Players can access the dealership by approaching the marked locations
2. Use the menu to browse and purchase available cars

## Configuration

The script can be configured in the `config.lua` file. You can adjust dealership positions, blip settings, marker settings, and the list of available cars.
